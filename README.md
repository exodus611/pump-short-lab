# pump-short-lab 🔥

База знаний и инструментов для бота, шортующего пампы мемкоинов на CEX-перпах.
Всё построено на двух слоях: (1) академические исследования pump-and-dump, (2) живые замеры механики бирж через публичные API.

**Статус:** исследования завершены 2026-09-11, пороги — стартовые, ждут калибровки на логе сигналов бота (см. `docs/03-backtest-backlog.md`).

## Структура

```
docs/
  01-pump-metrics-verdict.md      — наука о пампах + универсальные метрики и протокол входа
  02-exchange-mechanics-verdict.md— механика MEXC/BingX/Gate/Hyperliquid из живых API + персональные пороги
  03-backtest-backlog.md          — план калибровки порогов на собственном логе сигналов
config/
  per_exchange_thresholds.yaml    — стартовый конфиг бота по каждой бирже
scripts/
  collect_exchange_snapshot.py    — снимок живых данных 4 бирж (тикеры, funding, OI, контракты)
  analyze_snapshot.py             — кросс-биржевое сравнение: спреды, объёмы, OI, funding, листинги, глубина
data/
  snapshot-2026-09-11/            — сырой дамп API на момент исследования
```

## Главные выводы (коротко)

1. **Памп-математика:** средний организованный памп +65% за минуты, пик ~8 мин (медиана 1.5 мин), объём 13.5×, возврат к базе часто в течение часа → рабочий шорт = быстрый вертикальный памп, холд минуты–часы, цель 50–100% возврата хода. Медленные пампы = тренд, не шортуются.
2. **Вход не на вершине:** климакс (объём + верхняя тень) → откат 10–15% → слом структуры 1–5м → ниже VWAP. Стоп за хай.
3. **Биржи механически разные — пороги разные:**
   - **MEXC**: zero-fee пары, плечи до 300× (каскады), но медианный мем-перп полумёртвый ($0.2M/сут) → обязателен фильтр ликвидности.
   - **BingX**: funding каждые **4ч** — встроенный таймер размотки лонгов; ликвидность ровная → основная биржа (PF 7.36 в логе бота).
   - **Gate**: taker **0.075%**, тонкие стаканы, толпа в лонгах (L/S до 3.2) → мелкие цели не окупаются (PF 0.44); только лимит-входы и цели 70–100%, иначе off.
   - **Hyperliquid**: спред ~0, но maker платит, плечи 4–10×, funding 1ч → не основная площадка, а датчик (predictedFunding/OI) + majors.
4. **Home-venue правило:** PEPE→MEXC, TRUMP→Gate, WIF→BingX, FARTCOIN→MEXC/BingX/HL. Сигнал берём только там, где у монеты ликвидность (vol24 ≥ $5M, глубина 1% ≥ $300k).

## Обновить снимок данных

```bash
python3 scripts/collect_exchange_snapshot.py   # пишет в data/snapshot-<date>/
python3 scripts/analyze_snapshot.py data/snapshot-<date>
```

## Дисклеймер

Не является финансовой рекомендацией. Торговля перпами мемкоинов — экстремальный риск. Пороги из `config/` — стартовые значения для калибровки, а не гарантия.
